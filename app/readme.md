En simpel android fitness applikatation som
mäter och beräknar dina steg genom att använda sig av
Android Sensor Framework. Samt beräkna BMI baserat på
vikt och längd.

*Features*
- Login
- Egen personlig profil
- Profilegenskaper som namn, längd, höjd och vikt samt födelsedatum
- BMI kalkylator
- Stegräknare
- Editing för profilsida

*Språk och Teknik*
- Java
- Kotlin
- Android Studio
- XML
- SharedPreferences
- Android Sensor Framework


*A simple Android fitness application that tracks 
and calculates your steps using the Android 
Sensor Framework. It also calculates your BMI 
based on your weight and height.*
